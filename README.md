# Abyssal Devourer

Мультиплеерный босс-файт в стиле Terraria + Calamity.

## Стек
- Клиент: чистый HTML + Canvas + JavaScript
- Сервер: Node.js + Express + Socket.io
- Хостинг: OnRender (или любой Node-хостинг)

## Как запустить локально

```bash
# 1. Установить зависимости
npm install

# 2. Запустить сервер
npm start
```

Открыть в браузере: http://localhost:3000

## Управление
- **A / ←** — влево
- **D / →** — вправо
- **Пробел / W / ↑** — прыжок
- **Enter** — открыть/отправить чат

## Деплой на OnRender
1. Создай новый **Web Service**
2. Подключи репозиторий
3. Build Command: `npm install`
4. Start Command: `npm start`
5. Добавь переменную `NODE_VERSION` = `18` (или выше)
